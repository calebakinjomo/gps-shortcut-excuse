Relax — that cul-de-sac was a shortcut. The map just forgot to mention the lake in the middle of it.

## Run it

```sh
node main.ts
```

This writes exactly one line to `/output/entry.txt` — the GPS's excuse, in its own voice, for sending the driver down the wrong road, 100 characters, no setup notes and no explanation.
